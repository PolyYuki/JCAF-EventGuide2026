# JCAF デジタルイベントガイド (Japan Culture & Art Festival 2026)

Japan Culture and Art Foundation（JCAF）主催「Japan Culture and Art Festival」の公式来場者向けデジタルイベントガイドです。  
紙のプログラムの代わりに、来場者がスマートフォンのQRコードを読み取るだけで、会場マップ、出店ストール情報、ステージタイムテーブル、施設案内を日英バイリンガルで快適に閲覧できます。

---

## 🌟 主な機能と特徴

1. **会場マップ & スケーラブルSVGオーバーレイ**
   - 和モダンな会場庭園ベクターマップ（メインステージ、カルチャーステージ、飲食芝生エリア、心字池など）
   - 各ストール（飲食、伝統工芸、体験WS、物販）および施設（トイレ、案内所、救護所、入口等）のピン表示
   - パン（ドラッグ移動）、ピンチズーム・拡大縮小・リセット
   - カテゴリ別ピンフィルター（飲食、工芸、体験、物販、施設）
   - ピンタップ時のスムーズなボトム詳細カード表示
2. **出店ストール一覧 & 検索**
   - リアルタイム検索（店名、商品、タグ、日英両対応）
   - カテゴリフィルタータブ
   - お気に入り（ブックマーク）登録機能（ローカル保存）
   - 「地図で見る」ボタンでマップ該当位置への自動フォーカス＆パルス強調
3. **ステージプログラム & タイムテーブル**
   - Day 1 / Day 2 日程切替
   - ステージ別フィルター（メインステージ雅 / カルチャーステージ風）
   - 「現在開催中 (NOW PLAYING)」および「次回 (UP NEXT)」の自動ハイライト
   - 出演者紹介、演目解説アコーディオン
4. **来場者情報 & 施設ガイド**
   - トイレ、案内所、救護所、授乳室、エコステーション等の案内
   - 会場アクセス（最寄駅、シャトルバス、Googleマップ外部リンク）
   - 来場マナー・熱中症対策・写真撮影ルール
   - FAQ（よくある質問アコーディオン）
5. **完全バイリンガル対応 (日英)**
   - ヘッダーの切替ボタンでワンタップ切り替え（日本語 🇯🇵 / English 🇬🇧）
   - UIラベルだけでなく、店舗名、紹介文、ステージ情報、FAQもすべて日英完備
6. **Googleスプレッドシート データ連携 (ゼロコスト & 高セキュリティ)**
   - APIキーや秘密情報の埋め込み不要
   - Googleスプレッドシートの「Webに公開 (CSV)」URLから直接リアルタイム同期
   - オフライン時やURL未設定時も安心の高品質フォールバックデータ常備
   - LocalStorageキャッシュにより電波の悪いフェス会場でもサクサク動作

## 📊 Googleスプレッドシート連携手順

本アプリは、Googleスプレッドシートに記入された出店者情報やステージ情報を反映させることができます。

### 1. スプレッドシートの作成
スプレッドシートに以下の列（ヘッダー行）を作成します：

**出店者シート (Stalls)**:
`id, boothNumber, nameJa, nameEn, category, categoryJa, categoryEn, shortDescJa, shortDescEn, descriptionJa, descriptionEn, mapX, mapY, tagsJa, tagsEn, imageUrl, priceRange, highlightJa, highlightEn`

※ `mapX`, `mapY` はマップ上の位置パーセンテージ（0〜100）です。

### 2. Webに公開（CSV形式）
1. スプレッドシート上部のメニューから **「ファイル」 ＞ 「共有」 ＞ 「ウェブに公開」** を選択。
2. 形式を「ウェブページ」から **「カンマ区切り値 (.csv)」** に変更。
3. **「公開」** ボタンを押し、表示されたURLをコピー。

### 3. アプリケーションで設定
1. アプリ画面右上の歯車アイコン（設定ボタン）をタップ。
2. コピーしたCSVのURLを貼り付け、「保存して今すぐ同期」をクリック。

## 🌐 Vercelへのデプロイ手順

1. 本リポジトリを GitHub にプッシュします。
2. [Vercel](https://vercel.com/) にログインし、「Add New Project」を選択。
3. 当該リポジトリをインポート。
4. Framework Preset は `Vite` が自動選択されます（Build Command: `npm run build`, Output Directory: `dist`）。
5. 「Deploy」をクリックすると数十秒で全世界へ高速配信されます。
